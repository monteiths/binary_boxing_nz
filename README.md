# Binary Boxing NZ — GitHub Pages

1. Create a public GitHub repository (for example binary-boxing).
2. Extract this ZIP on your computer.
3. In the repository choose Add file > Upload files.
4. Upload all extracted files directly into the repository root (not the ZIP or its containing folder).
5. Commit the files to main.
6. Open Settings > Pages. Choose Deploy from a branch, main, /(root), and Save.
7. When publishing completes, use the website link shown on the Pages settings screen.
8. In Google Sites, choose Insert > Embed and paste that website link. Resize the game frame and publish.

The five required game files must stay together: index.html, style.css, game.js, arena.png, landing.png.

Round 1: 4 bits, 5 seconds, labels shown.
Round 2: 4 bits, 4 seconds, labels shown.
Round 3: 5 bits, 5 seconds, labels shown.
Round 4: 4 bits, 3 seconds, labels hidden.
Boss: 6 bits, 10 seconds, labels hidden.

Ten correct answers beat each alien. Five lives per round. Wrong answers and timeouts cost a life. Losing restarts at round 1.

Controls: tap/click answers or keys 1–4. Optional sound. Opening animation has a Skip intro button.

You can also run the game locally by opening index.html in a browser.
